# witchyHouse（女巫小店）

Cocos Creator 3.8 製作的俯視角女巫採集 × 商店經營遊戲。到森林採集材料、回自己的店裡上架定價、煉製藥水賣給上門的動物顧客，順便接 NPC 任務、升級店鋪、佈置房間。

## 線上試玩

<https://crashoxo.github.io/witchyHouse/>

建議用桌機瀏覽器（鍵盤操作）。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| WASD / 方向鍵 | 移動 |
| 按住 Shift | 衝刺（速度 ×1.7，動畫換成跑步） |
| 滑鼠左鍵點地面 | 走到該處（按方向鍵可隨時接手；不會因此走出地圖換場景） |
| J / 空白鍵 | 施放魔法彈 |
| E | 採集、交談、進門、開商店／鍋爐 |
| Q | 開任務簿 |
| Tab（或 I） | 開玩家資訊：物品詳情／村民友誼／日曆 |
| 空白鍵 / Enter | 對話推進 |
| Esc | 關閉視窗 |

走到地圖邊緣會切換場景：森林 → 右邊 → 城鎮 → 小屋 → 自己的店 → 右上 → 煉藥室。

## 內容

- **森林**：蘋果樹、莓果叢、香草圃等採集點，隨機產量與稀有掉落
- **城鎮**：石板街道與噴泉廣場、西側城門、東側溪流與三座橋；雜貨鋪收購材料、花店買裝飾、三位 NPC 提供任務鏈
- **自己的店**：材料／藥水上架定價，動物顧客上門購買，自由拖放佈置房間
- **煉藥室**：10 種配方、6 幀熬煮動畫
- **系統**：背包、金幣、存檔（localStorage）、店鋪升級、任務系統、對話系統、更新公告板
- **每日循環**：時間與日夜天色、營業時間 08:00–20:00、當日結算、店鋪名聲（影響來客）
- **年曆**：一年 12 個月 × 28 天、四季（影響天色與採集）、8 個節日
- **玩家資訊**（Tab）：物品詳情、村民友誼、當月日曆
- **後花園**：從店裡右邊過去，三種花可種／澆水／採收，花可入藥或販售
- **糖果鎮**：森林北邊的新地圖，軟糖鱷商行進貨、時晶守衛與小芽苗可對話，街上有軟糖鱷與薑餅人走動
- **背包與倉庫**：背包按 B 開（分頁、可升級），房間木箱是倉庫；材料一進城鎮自動歸位
- **換裝**：房間衣櫃四套造型，換上之後場景裡的小人也跟著換衣服
- **地圖移動**：出入口會發光標示，走上去就換場景（不必按鍵）；一張地圖可以有多個出口
- **主角**：黑袍緋紅緞邊的哥德女巫，八個方向各有站姿、走路與跑步循環，另有採集／施法／睡覺的動作圖

### 2026 / 08 / 02

這一批把遊戲從「一座森林加一個城鎮」擴成四張地圖的世界，並補上背包／倉庫、換裝、糖果鎮。

**後花園**

- 從店裡右邊過去，12 塊花圃（開墾了才能種，初始 6 塊）
- 三種花：薰衣草、毛地黃、星鈴花。花店買得到種子，森林採集也有機率掉
- 種下是乾土、澆水才變濕土；**沒澆水的種子不會發芽**
- 澆水後 1 個遊戲小時開花可以摘；水撐 1.5 小時，撐得過一夜
- 澆水會從澆花器的壺口噴出水弧，落點濺起水花
- 花可以賣，也可以進藥水室煉成安眠藥水／花香水／星光藥劑

**糖果鎮**

- 從森林**往北**走出邊界就到，地圖跟主城鎮一樣大（3200×2048）
- 地面是草地＋巧克力磚拼的，房子與裝飾都是可以在編輯器裡拖動的節點
- 軟糖鱷商行賣六樣別處買不到的貨，買回自己店裡賣有價差可賺
- 時晶守衛與小芽苗可以聊天；街上有軟糖鱷與薑餅人走來走去

**背包與倉庫**

- 背包按 **B** 開，分頁看材料／花與種子／藥水；容量從 12 種升到 21 種
- 房間裡的木箱是倉庫（40 種），走近按 E 存取，可以一鍵「全部存入」
- **採集完走進城鎮，材料與花會自動歸位到倉庫**（種子與藥水留在身上）
- 收購、煉藥、上架都改成「背包＋倉庫」一起算，不必先跑回去拿

**換裝**

- 房間衣櫃四套造型，換上之後走路、採集、澆水、摘花、施法、睡覺的小人全部跟著換

**其他**

- 煉藥可以一次做 ×1／×5／最大，一批只播一次動畫
- 村民長高了一點，也多了一位兔子魔女
- 進屋子的光圈改到房子門口
- 修好：花開了卻摘不到（成長階段的最後一格其實是枯穗）

### 2026 / 07 / 28

這天的主軸是「看得出來哪裡能走」——出入口以前完全沒有視覺，不熟遊戲的人根本不知道能走過去。

**傳送點會發光**

- **出入口都亮起來了**（`PortalGlow`）：地上一圈會呼吸的青色光暈、往上一道光柱、飄起的光點；冷青色是刻意跟城鎮路燈的暖黃分開，代表「這是通道」而不是照明
- **靠近會顯示「前往○○」指示牌**，箭頭指著該走的方向（箭頭是畫出來的，不吃字型）
- 光暈畫在夜色色板**之上**，入夜也不會被壓暗；開面板或對話時跟時鐘一樣凍結
- 門是執行期從場景樹掃出來的，所以之後新增的門會自動發光，不必額外設定

**邊界出口改成一個定點**

- 以前走到那一側的**任何地方**都會換場景，光暈只好畫成沿著整條邊的長光幕；現在整條邊只有**一個發光的點**能過去，其他地方就是牆
- 定點位置寫在 `data/portals.ts`：森林東側、城鎮西側（對準往西的泥土路）、店內門口
- 光暈畫得比實際的門略小，且與判定讀同一份資料——**看得到的地方一定走得過去**

**走上去就過圖**

- 門不用再按 E，**走上去就會過去**（E 仍然可用）。這樣按鍵分工才乾淨：**E ＝跟東西互動**（櫃台、鍋爐、NPC、採集），**走上去＝換地方**
- 顯示提示的距離與真正觸發的距離分開：提示維持大範圍（遠遠就看得到這是門），觸發縮到跟地上光圈差不多大，才不會走過房子旁邊就被吸進去
- 出生點若剛好在門旁邊（藥水室就是），門會先上鎖，等玩家走開一次才啟用——否則一進房間就會被彈回去、兩個場景無限來回

### 2026 / 07 / 26

這天的主軸是「讓時間有意義」——一天有了開始與結束，一年有了季節。

**每日循環**

- **營業時間 08:00 – 20:00**：顧客只在這段時間上門，打烊後可以安心去採集或睡覺（經營商店面板會顯示現在營業中／已打烊與今日營收）
- **當日結算**：一天結束（睡覺或撐到 02:00 昏倒）會跳出結算——店裡營收與賣出明細、材料收購收入、支出、採集／煉製數量、當日賺到的名聲（`DailyLog` 記帳 ＋ `DaySummaryPanel` 顯示）
- **店鋪名聲**（`Reputation`，5 級稱號）：每賣出一件累積名聲、當日營收再結算一筆；名聲越高顧客來得越快、同時人數越多（疊在「招牌」升級之上），HUD 左上常駐顯示
- **昏倒也有睡覺過場**：撐到 02:00 倒下時一樣會演睡覺畫面，而且**醒來一定在自己房間**（人在森林或城鎮也會被送回去）

**年曆與季節**

- **年曆**：一個月 28 天、一年 12 個月（336 天），每 3 個月一季——一～三月春、四～六月夏、七～九月秋、十～十二月冬。日期寫成「第 1 年 3 月 16 日（春）」
- **時鐘**：中央的牛皮紙框顯示月份數字與日數，上方緞帶會換上**當季圖標**（嫩芽／太陽冰棒／楓葉橡實／雪人）
- **季節有感**：冬天天黑得早、夏天拖得晚（天色曲線隨季節前後挪）；每季有**當季盛產材料**，採集時多給一個、稀有掉落機率也提高
- **節日**：一年 8 個節日，當天客人特別多；日曆上會標出來

**玩家資訊面板（Tab 或 I）**

- **物品頁**：所有材料／藥水的圖示、持有數、收購價、建議售價與說明，可翻頁
- **村民頁**：頭像、住處、介紹與友誼度愛心
- **日曆頁**：當月 28 天月曆，標出今天與節日，附當季盛產材料
- **村民友誼**：每天第一次跟同一位村民交談會加友誼，最多 5 顆心

**日夜天色**

- 森林與城鎮加入日夜天色：白天全亮、傍晚轉暖橘、入夜染深藍、清晨藍光淡出（同一張地圖站著就會隨時間漸變，不必換場景）
- 天色用一層全螢幕色板疊在世界之上、HUD 之下，依 `TimeSystem` 連續變化（`DayNightTint`，只在森林/城鎮套，室內不影響）
- 城鎮路燈入夜會亮起暖黃燈光：傍晚漸亮、整夜全亮、天亮熄滅，光暈即時黏在每盞燈上（`LampGlow`）

## 專案結構

```
assets/scripts/        遊戲腳本（TypeScript）
assets/art/            場景與角色美術
assets/art/town-tiles/ 城鎮路面與景物素材，由 town.scene 的節點直接引用
assets/resources/      執行期載入的圖（商品／顧客／頭像／裝飾／藥水／UI）
docs/                  web-mobile 建置產物，GitHub Pages 由此發佈
```

城鎮的街道在 `town.scene` 的 `World/Roads` 底下（不做前後遮擋，永遠畫在角色下方），
噴泉、城門、路燈等景物在 `World/Props` 底下（依 y 座標排序，會擋住角色）。
兩者都是一般節點，直接在編輯器裡拖曳就能調整。

## 建置

用 Cocos Creator 3.8.8 開啟專案後建置 web-mobile（4 個場景都要勾），或用命令列：

```
CocosCreator.exe --project <專案路徑> --build "configPath=<buildConfig.json>"
```

再把 `build/web-mobile` 的內容覆蓋到 `docs/`（保留 `.nojekyll`）並提交。
