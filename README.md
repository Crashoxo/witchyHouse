# witchyHouse（魔女商店）

俯視角的女巫「採集 × 商店經營」遊戲。到森林採材料、回自己的店裡上架定價、
煉藥種花，賣給上門的動物顧客，順便接 NPC 任務、升級店鋪、佈置房間。

## 線上試玩

<https://crashoxo.github.io/witchyHouse/>

建議用桌機瀏覽器（鍵盤操作）。⚠️ 第一次載入要等一下 —— Unity WebGL 得先下載
整包遊戲再在瀏覽器裡解壓縮。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| `WASD` / 方向鍵 | 移動 |
| 按住 `Shift` | 衝刺（速度 ×1.7，動畫換成跑步）|
| 滑鼠左鍵點地面 | 走到該處（按方向鍵可隨時接手）|
| `J` / 空白鍵 | 施放魔法彈 |
| `E` | 採集、交談、進門、櫃台、睡覺、澆花 |
| `B` | 背包 |
| `Q` | 任務簿 |
| `Tab` / `I` | 女巫的手札（物品詳情／村民友誼／日曆）|
| `R` | 店內佈置模式 |
| 空白 / `Enter` | 對話推進 |
| `Esc` | 關閉視窗 |

走到地圖邊緣會換場景：森林 → 右邊 → 城鎮 → 小屋 → 自己的店 → 藥水室／後花園。

## 內容

- **森林**：蘋果樹、莓果叢、香草圃等 84 個採集點，隨機產量與稀有掉落
- **城鎮**：石板街道與噴泉廣場、溪流與橋；雜貨鋪收購材料、花店買裝飾、三位 NPC 給任務
- **自己的店**：等距房間，貨架上架定價、顧客上門、佈置模式拖家具（`R`）
- **藥水室**：鍋爐煉藥、倉庫、床（睡覺跳到隔天並結算當日帳）
- **後花園**：種花、澆水、收成
- **糖果鎮**：軟糖鱷商行進貨賺價差

## 這是 Unity 版

原本是 Cocos Creator 3.8 做的，2026-09 整包移植到 **Unity 6.6 (6000.6.0f1)**。

**Cocos 版的完整歷史留在 [`cocos-legacy`](../../tree/cocos-legacy) 分支**，沒有刪。

## 開發

```
Unity Hub → Add → 選這個資料夾
```

1. 第一次開要等它匯入 260 張圖並建 Library
2. 選單 **Witch Shop → 建立 UI 設定檔**（第一次一定要跑）
3. 選單 **Witch Shop → 重新登記所有場景**
4. Project 視窗開 `Assets/Scenes/main.unity` → ▶ Play

⚠️ 切換地圖是在 Project 視窗對 `.unity` 檔點兩下 ——
**「建立◯◯場景」那些選單是從頭重蓋**，平常不要按。

### 常用的幾支

| 事情 | 怎麼做 |
|---|---|
| 確認程式編不編得過（不用開 Unity）| `bash tools/typecheck.sh` |
| 改了中文字串 | `python tools/subset_font.py`（字型是子集化過的，不跑新字會變豆腐）|
| 出網頁版（本機看）| 選單 **Witch Shop → 建置 → 網頁版（建好直接開瀏覽器）** |
| 出網頁版（更新這個網站）| 選單 **Witch Shop → 建置 → 網頁版（給 GitHub Pages）**，建到 `docs/` 之後 commit push |
| 測試用工具 | 選單 **Witch Shop → 測試用**（塞道具、給錢、塞一天的營業紀錄、清存檔）|
