# 貨架重畫步驟（PixelLab，四個朝向）

第一批十六款已經在遊戲裡了，畫得很好。要重畫**只為了一件事：朝向**。
（投影角度我已經用程式校正掉了，那個不是重畫的理由，但順便從源頭做對更乾淨。）

---

## 為什麼要重畫

你第一批的 `metadata.json` 寫著 `"directions": 1` —— 一款貨架只有一個朝向，
**背板永遠朝畫面左上、開口朝右下**。

店裡是等距房間，有**兩面後牆**：

- **左後牆**（格子 `gx = 0` 那一排）→ 現在這批擺上去剛剛好，背貼牆、開口朝店裡。
- **右後牆**（格子 `gy = 0` 那一排）→ 現在這批會變成**側著站**，看起來就怪。

程式鏡像做得到，但**會把左上光源翻成右上**，一整排看過去會發現光打反了，所以不做。

順帶一提，`Objects` 出的圖不是真 2:1 等距（實測往左上只有 1/3 斜率、往右上才 1/2），
匯入時我用仿射校正拉回來了。用下面那張參考圖的話，生成器會照著正確的角度畫，
校正那一步就能關掉，少一次重取樣。

---

## 怎麼設

`www.pixellab.ai` → 上方 nav 的 **Objects** → **Create Object**

| 欄位 | 填什麼 |
|---|---|
| **Style Reference Images** | 上傳 **`貨架_參考圖_給PixelLab.png`**（桌面上，或 `tools/art-guide/shelf-style-ref.png`） |
| **Directions** | **4** ← 這次的重點 |
| Size / View | **會不見，那是正常的** —— 上傳參考圖之後尺寸與視角就跟著參考圖走（72px） |
| Object Description | 見下面 |

那張參考圖就是**你自己那款素面方架、校正成正確 2:1 之後的樣子**。
用你自己的圖當參考，木色/描邊/打光才會跟已經在遊戲裡的那批一致。

⚠️ 參考圖裡刻意**沒有**任何格線或標記 —— 做牆的時候把有粉紅標記線的圖當參考，
結果粉紅線被生成器當成圖案畫進去了。

---

## 逐步操作

> 欄位名稱是照你 2026-08-18 給我的截圖記下來的（我沒辦法自己開你登入後的 PixelLab）。
> 如果哪一格長得不一樣，截個圖給我，我再對。

**1.** `www.pixellab.ai` → 上方 nav 點 **Objects** → **Create Object**

**2. 先上傳參考圖**（順序重要，因為它會改變下面的欄位）
   `Style Reference Images` → 上傳桌面的 **`貨架_參考圖_給PixelLab.png`**
   → 上傳完 **`Size` 滑桿與 `View` 下拉會消失**，欄位標題會變成 `1/4 at this size` 之類的字樣。
   **這是正常的**，代表輸出尺寸改成跟著參考圖走（72px）。

**3. `Directions` 選 `4`** ← 這次唯一真正要改的東西

**4. ⚠️ `Object Description` 不要拿來寫風格咒語** —— 實測（2026-08-25）**這一格本身就是一個物件**：
   我請他把風格句貼進去，結果多生了三個「架子上擺水晶／乾燥花束／藥水瓶」的東西
   （metadata 裡叫 `base`，prompt 就是那句風格句）。額度就這樣花掉了。
   要嘛留空、要嘛就寫一個你真的想要的物件。**風格詞塞進每個 item 的描述裡。**

**5. `Describe each item (1)`** —— 這次只做一款，貼這句：

```
simple box shelf with visible wood grain, 2:1 isometric view,
warm reddish brown wood, soft light from the top left, transparent background, no text
```

### ⚠️⚠️ 決定投影對不對的是**提示詞**，不是 Style Reference

實測（2026-08-25，量底座的長邊斜率，地板要 0.500）：

| 來源 | 提示詞有寫 `2:1 isometric view`？ | 長軸 |
|---|---|---|
| 第一批十六款貨架 | ✗ | 0.357 ✗ |
| 用參考圖重出的 simple_box（item 欄） | ✗ | 0.333 ✗ |
| 三個展示架（Object Description 欄） | **✓** | **0.500 ✅** |

**Style Reference 只管風格（木色/描邊/上光，那部分它做得很好），不管角度。**
角度是被提示詞決定的 —— **所以每一款的描述都要自己帶上 `2:1 isometric view`**，
不能只寫在整體那格。下面的十六句已經加好了。

這樣出來的圖投影本來就是對的，`import_furniture.py` 會自動判斷（`FIX_PROJECTION='auto'`）
而不去動它。

**6. Generate**，等它出圖。

## 挑圖：四個朝向要逐一放大看

⚠️ **PixelLab 很常同一個方向給兩份，其中一份是壞的** —— 這個專案踩過兩次：
女巫跑步的 `north` 有一份整組是疊影、施法的 `north-west` 有一份每幀帽子都在跳。
**縮圖看不出來，一定要放大**。

四個朝向都確認這幾件事：

- [ ] **背板朝四個不同方向**（左上／右上／左下／右下各一個），不是四張都一樣
- [ ] **光源固定在左上**，不要跟著物件一起轉（轉了的話一整排看過去會發現光打反）
- [ ] 木色、描邊粗細跟參考圖一致（不然會跟已經在遊戲裡的十六款長得不像）
- [ ] 背景透明、沒有文字、沒有地板或影子畫進去

有一向不行就**只重出那一向**，不用整組重來。
